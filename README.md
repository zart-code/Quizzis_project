# Отчёт о состоянии проекта — Квиз-платформа

## Общая информация

Проект представляет собой веб-платформу для создания и прохождения квизов с разделением ролей: **Админ**, **Учитель**, **Ученик**.  
Ниже приведена детальная сводка о реализации требований, обсуждавшихся на этапе проектирования.

---

## 🟢 Реализованный функционал

### Авторизация и роли
| Функция | Статус |
|---------|--------|
| Регистрация пользователя | ✅ Реализовано |
| Вход для всех ролей | ✅ Реализовано |
| Роли: ученик, учитель, администратор | ✅ Реализовано |

### Функционал по ролям

| Роль | Возможности |
|------|--------------|
| **Админ** | Создание квизов, бан пользователей, удаление любых квизов, изменение данных профиля любого пользователя |
| **Учитель** | Создание квизов, удаление **своих** квизов, изменение своих данных |
| **Ученик** | Подключение к квизам, прохождение, просмотр результатов |

### Панель администратора
- Отображение количества пользователей и квизов  
- Список всех квизов с возможностью блокировки  
- Список последних жалоб  
- Возможность блокировки пользователя / квиза  

> ✅ **Всё реализовано**

### Типы вопросов в квизах

- ✅ Текстовый ответ  
- ✅ Одиночный выбор

## 🟡 Частично реализованное / отклонения

| Требование | Статус | Пояснение |
|------------|--------|------------|
| Подключение по QR-коду | ❌ Не реализовано | — |
| Тип вопроса «тестовый с проверкой учителя» | ❌ Не реализовано | — |
| Синхронный квиз с ручным переключением вопросов | ❌ Не реализовано | Реализована синхронность (ожидание всех участников), но создатель **не может** вручную переключать вопросы |

---

## 🔴 Ключевые несоответствия требованиям

> **Синхронный квиз:**  
> По требованию: «пока не ответят все, не происходит смена вопроса. Создатель должен иметь возможность переключать вопросы вручную».  
> **Факт:** ожидание всех работает, но ручное переключение вопросов отсутствует.
> Отсутствие возможности входа без полной регистрации
---

## Итог

Проект в настоящий момент во многом соответствует большинству согласованных требований.  
Основные **нереализованные** элементы:
- QR-код для подключения
- Вопросы с проверкой учителя
- Ручное переключение вопросов в синхронном режиме
